# Changes

## 2.10.2.0

- Build result descendants only when expanded, preserving XPath strings for navigation, export, and removal. Show All explicitly builds the full tree.
- Create element labels from XML metadata rather than repeatedly serializing descendant subtrees.
- Cache sibling indices for navigation paths.
- Reuse the evaluated XPath iterator and publish each query's matches in one UI update.
- Skip namespace-removal serialization/reparsing when there are no default namespaces, and deduplicate namespace replacements.
- Debounce Auto Search by 350 ms; cancellation/restart runs the most recent queued query.
- Clear stale selections at the start of a search and handle empty/cancelled/error completion safely.
- Add a reproducible 893 KB / 24,023-line / 10-match benchmark and namespace/path/export/removal regression checks.
- Extend the Notepad++ smoke test to cover lazy expansion, editor navigation, scalar/empty/invalid queries, and cancellation/restart.

## 2.10.1.0

- Build the DLL directly from the corrected C# source, with six native x64 exports generated by ILDasm/ILAsm.
- Preserve 64-bit addresses throughout native array and menu-pointer arithmetic.
- Allocate and initialize enough memory for UTF-16 filename buffers; dispose temporary arrays after use.
- Use pointer-sized docking icon handles and Scintilla position/count fields.
- Read the notification header alone when only the notification code is needed.
- Guard per-tab query saving until initialization, and prevent reentrant updates.
- Restore per-tab XPath query persistence.
- Catch managed exceptions at the native notification boundary and record diagnostics in `%TEMP%\XPatherizerNPP-errors.log`.
- Include direct regression tests and an optional in-process Notepad++ smoke test.
- Point the About dialog, XPath help, keyboard help, and download links to the [x64 branch](https://github.com/debadattanaik/XPatherizerNPP-x64/tree/x64).

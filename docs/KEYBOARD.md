# Keyboard shortcuts

Use the XPatherizerNPP settings dialog to select a plugin command, choose a key, and enable Ctrl, Alt, or Shift modifiers. Apply or save your changes. Avoid key combinations already assigned to Notepad++ commands or other plugins.

The key selector uses Windows Forms key names such as `F1`, `F2`, letters, and navigation keys. Choose a key from the available list rather than typing a combined shortcut into the key field.

Return to the [project's x64 branch](https://github.com/debadattanaik/XPatherizerNPP-x64/tree/x64).
